Try each shape

  1. Browser tab: just use this page in Safari or Chrome.
  2. Add to Dock: Safari → File → Add to Dock… Launch it from the Dock / Spotlight / Launchpad. Note the window, the Dock icon, ⌘-Tab, and that it has no URL bar.
  3. Server down: Ctrl-C the serve.py terminal, then reopen or reload the Dock app. You should get the offline page, not a browser error.
  4. Restart: run serve.py again and press "Try again".
